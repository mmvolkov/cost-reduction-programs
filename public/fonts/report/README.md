# PDF fonts

DejaVu Sans regular and bold, from the DejaVu fonts distributed with this environment. License: LICENSE.txt (Bitstream Vera license with DejaVu additions in the public domain).

The original fonts were subset with fontTools 4.61.1 (pyftsubset), preserving U+0000–052F, U+2000–206F, U+20A0–20CF, U+2100–214F, U+2190–21FF and U+2212. Each module exports base64 TTF bytes, not executable font-fetching code. This covers the canonical Russian report, ₽, №, nonbreaking spaces and punctuation. The report does not contain arbitrary chat text.

Upstream: https://dejavu-fonts.github.io/
