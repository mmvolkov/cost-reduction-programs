# Проверка

## Автоматическая

`npm run check` проверяет синтаксис и запускает встроенный Node test runner. Покрываются:

- линейный разгон, денежные единицы, первый год и устойчивый эффект;
- нулевые/отрицательные сценарии, граница окупаемости ровно 120 месяцев;
- диапазоны и недопустимые числовые значения;
- server-only ключ, фиксированный endpoint/model, контекст и лимит ответа;
- код доступа, согласие, выключенный AI, недоступные профили;
- слишком большие запросы, сторонний origin, предварительные rate limits;
- запрет клиентских endpoint override, ограничения профилей;
- static path traversal, dotfiles и security headers;
- отсутствие утечек текста upstream ошибок;
- авторитетные серверные данные выбранных мер и отказ для неизвестного ID.

## Не подменять подтверждением

Внешний AI-вызов с реальным ключом, создание GitHub repo, push, CI для удалённого commit и публичный hosting требуют отдельных проверок. В автоматических тестах upstream подменён. Проект не содержит реального API key и не публикует сайт автоматически.
