# Проверка

## Автоматическая

`npm run check` проверяет синтаксис и запускает встроенный Node test runner. В обновлении оформления 11 ноября 2026 года прошли 74 теста. Покрываются:

- линейный разгон, денежные единицы, первый год и устойчивый эффект;
- нулевые/отрицательные сценарии, граница окупаемости ровно 120 месяцев;
- диапазоны, недопустимые значения и обязательные явно подтвержденные входные данные;
- детерминированный отчет без вызова модели, включая 12 млн ₽/год, 10%, внедрение 0,2 млн ₽ и поддержка 0,02 млн ₽/месяц: 0,76 млн ₽ за первый год и окупаемость 2,5 месяца при нулевом разгоне;
- server-only ключ, фиксированный endpoint/model, контекст и один начальный system message;
- T=0 по умолчанию и сохранение явного выбора температуры в настройках;
- код доступа, согласие, выключенный AI и недоступные профили;
- слишком большие запросы, сторонний origin и предварительные rate limits;
- постоянный общий бюджет 100 попыток в сутки UTC, две параллельные попытки, предел 1000 output tokens;
- запрет обхода глобального ограничения подменой IP-заголовков;
- запрет клиентских endpoint override, ограничения профилей;
- static path traversal, dotfiles и security headers;
- отсутствие утечек текста upstream ошибок;
- авторитетные серверные данные выбранных мер и отказ для неизвестного ID;
- единый системный шрифт, палитра Scout, роли размера текста, естественный перенос заголовков и минимальная высота управляющих элементов.

Статическая сборка: `PUBLIC_API_BASE_URL=https://scout-argument.ru/cost-reduction-programs/api/ node scripts/build-pages.mjs`.
Она не содержит серверных файлов и секретов. Docker build и smoke-test выполняются отдельным заданием CI.

Проверены фактические CSS-размеры окна (ширина × высота), измеренные в браузере:

| CSS viewport | Масштаб браузера | Результат |
| --- | --- | --- |
| 390 × 378 | 200% | Пройдено |
| 768 × 757 | 100% | Пройдено |
| 1280 × 841 | 90% | Пройдено |
| 1440 × 946 | 80% | Пройдено |

Масштаб указан явно: узкий режим проверен при 200%, широкие CSS-размеры получены штатным изменением масштаба и размера окна. Это не утверждение о проверке каждого размера при 100%.

На каждом размере проверены первый экран, девять карточек мер, три кейса, калькулятор, чат и настройки. Горизонтальная прокрутка не обнаружена; кнопки и раскрываемые заголовки имеют высоту не меньше 44 CSS px. Проверены раскрытые пояснения меры, методика и справка настроек. На узких размерах окно настроек прокручивается по вертикали внутри viewport.

Стресс-сценарий: годовая база и разовые вложения по 1 000 000 млн ₽, поддержка 100 000 млн ₽/месяц, снижение 10%, разгон 0. Результат −2 100 000 млн ₽ и отсутствие окупаемости за десять лет помещаются без обрезания. Длинный русский текст в поле чата не отправлялся и не создавал горизонтальной прокрутки.

Контрольный расчет 12 / 10% / 0,2 / 0,02 / 0 подтвержден через интерфейс: 0,76 млн ₽ за первый год, 0,96 млн ₽ в год на полном ходу и 2,5 месяца окупаемости. T=0 сохранено по умолчанию; согласие на передачу текста модели оставалось выключенным. Реальных AI-вызовов не было.

## Границы подтверждения

Автоматические тесты используют подмененный upstream. В ходе проверки оформления внешняя модель не вызывается, реальный API key не нужен. Свободный AI-ответ не является проверенным финансовым расчетом; подтвержденный отчет строит детерминированный калькулятор.

Успех локальных тестов не подтверждает CI, публичный GitHub Pages или развертывание на сервере. Их проверяют отдельно для конкретного коммита. Существующий workflow публикует GitHub Pages после push в `main`; раздел на сервере обновляется отдельной командой владельца. Бюджет AI хранится в постоянном volume и при обычном пересоздании контейнера не сбрасывается. Лимит попыток не является финансовым потолком.
