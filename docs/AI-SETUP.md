# Настройка ИИ-помощника

Требуется Node.js 22+. Зависимостей нет. Статический сайт работает без ИИ; помощник отключен, пока не заданы **и** `AI_API_KEY`, **и** `AI_ACCESS_CODE`.

1. Скопируйте `.env.example` в локальный `.env`.
2. Укажите новый API-ключ и длинный случайный код доступа. Не используйте опубликованные или ранее раскрытые ключи; отзовите их у провайдера. Не сохраняйте секреты в Git, HTML, браузерном коде, URL или скриншотах.
3. Запустите `node --env-file=.env server.mjs`. По умолчанию адрес `http://127.0.0.1:3000`; `HOST` и `PORT` меняют привязку.
4. Проверьте `/api/health`, `/api/config`, затем выполните тесты: `node --test test/server.test.mjs`.

Провайдер по умолчанию: Softline, `https://api.ai-assistants.softline.com/v1`, модель `qwen3.8-27b-nvfp4`. Доступность модели зависит от аккаунта провайдера. API должен поддерживать OpenAI-совместимый `/chat/completions` и `max_tokens`.

## Передача данных и лимиты

POST `/api/chat` принимает `providerId`, `accessCode`, обязательное `consent: true`, историю `messages`, необязательные `context` и `temperature` (0–1). История: до 20 сообщений, до 6000 символов каждое и 24000 суммарно. Максимум тела 48000 байт. Допустимые роли: `user`, `assistant`; последнее сообщение должно быть пользовательским. Перед отправкой интерфейс должен получить явное согласие пользователя: история и выбранный расчетный контекст уйдут выбранному внешнему провайдеру. Не отправляйте персональные данные, коммерческую тайну и секреты. Код доступа передается только своему серверу, не модели.

Контекст ограничен списком до 30 `measureIds` и `calculator`: `annualSpend`, `savingsPercent`, `implementationCost`, `monthlyCost`, `rampMonths`. Денежные значения — **миллионы рублей**. Прочие поля контекста не передаются. Системная инструкция требует обозначать предположения и иллюстративные примеры и не обещать гарантированную экономию. Ответ модели отображайте через `textContent`, не `innerHTML`.

По умолчанию: 8 запросов/минуту и 100/сутки на IP, 500/сутки глобально; учитываются и неудачные попытки до проверки кода. Сутки — UTC. Ответ модели ограничен 1000 токенами (настройка 64–2000); тайм-аут 45 секунд. Лимиты задаются переменными из примера. Повторные попытки не выполняются автоматически. Тексты запросов, секреты и подробности ошибок провайдера не логируются сервером.

## Дополнительные провайдеры

Администратор может задать `AI_PROVIDERS_JSON`: массив объектов `{id,label,baseUrl,model,apiKeyEnv}` и `AI_ALLOWED_HOSTS`: точные HTTPS-хосты через запятую. Ключ хранится отдельно в переменной с именем `apiKeyEnv`. Не используйте IP, localhost, непроверенные домены или внутренние сервисы; DNS разрешенных доменов должен контролироваться доверенным провайдером. Разрешен только HTTPS/443 без учетных данных, query и fragment. Перенаправления запрещены. Некорректные профили исключаются. Браузер не может задавать URL, модель или ключ. `/api/config` показывает только готовые профили и публичные id/название/модель.

## Production

- Не публикуйте открытый прокси без кода доступа. Общий код предназначен для ограниченного пилота, не заменяет персональную аутентификацию и разграничение ролей.
- Используйте TLS reverse proxy; задайте `PUBLIC_ORIGIN=https://ваш-домен` без завершающего слеша, сохраните исходный `Host` и ограничьте допустимые хосты на прокси. POST с чужим Origin отклоняется. Для небраузерных клиентов без Origin остается обязательный код доступа.
- Сервер намеренно не доверяет `X-Forwarded-For`. За прокси все запросы могут иметь один IP и общий IP-лимит. Для корректных индивидуальных лимитов внедрите проверенную конфигурацию доверенных прокси, не доверяйте произвольным заголовкам клиента.
- Лимитер хранится в памяти процесса и сбрасывается при перезапуске. Для нескольких реплик или публичного production используйте общий Redis/шлюз лимитов, лимит расходов на стороне провайдера, контроль размера/скорости запросов на прокси и мониторинг без содержимого сообщений.
- Настройте HSTS на TLS-прокси. CSP разрешает только собственные скрипты, стили и подключения; встроенные скрипты/стили не разрешены.
- Храните секреты в менеджере секретов, регулярно меняйте ключ и код, перезапускайте процесс после изменения. Не включайте тела запросов и заголовок Authorization в журналы reverse proxy/APM.
- Закройте исходящий доступ к внутренним сетям на уровне инфраструктуры. Allowlist не заменяет сетевую защиту от ошибочной настройки DNS.

### Контекст программы

Браузер передаёт идентификаторы выбранных мер. Сервер сам находит их названия, шаги, метрики и ограничения в `public/data.js`; неизвестные идентификаторы отклоняются. Клиентские описания не заменяют эту библиотеку. Числовые поля расчёта передаются только после выбора «Разобрать расчёт с AI» и явной отправки с согласием. Диалог и код доступа хранятся в памяти вкладки, не в localStorage. Нажатие «Очистить» удаляет локальную историю, но не удаляет уже переданные провайдеру данные.

Полный набор параметров калькулятора сервер пересчитывает общей функцией `public/calculator.js` и передаёт модели проверенные результаты, включая помесячный эффект и окупаемость. Модель не должна заменять эти вычисления собственной арифметикой.
